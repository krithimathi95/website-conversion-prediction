# Website Conversion Prediction using Scikit-learn

This project predicts whether a website visitor will convert based on session duration, pages viewed, traffic source, device type, returning visitor status, and cart activity.

## Run
1. Install dependencies:
   pip install -r requirements.txt
2. Train the model:
   python train_model.py
3. Make a sample prediction:
   python predict.py

The included dataset is synthetic and stored in `data/website_conversion.csv`.
